## 📌 Technical Overview
**FruitList** showcases clean iOS component separation with mockable service architectures, smooth navigation hierarchies, and full XCTest suite coverage.

### 💼 Technical Highlights
- **Decoupled Service Layer**: `FruitService.swift` providing simulated asynchronous network latency and data modeling.
- **Master-Detail Navigation**: Fluid transitions between inventory lists and high-detail viewports (`FruitDetailView.swift`).
- **Comprehensive Testing**: Includes unit tests (`FruitListTests.swift`) and automated launch UI tests (`FruitListUITests.swift`).

## 🚀 Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/snaimio/FruitList2026.git
   cd FruitList2026
   open FruitList2026.xcodeproj
   ```
2. Run tests via `⌘ + U` or run the app with `⌘ + R`.
